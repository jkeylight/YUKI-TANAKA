RULE

No project ships as a single HTML file.


Every project uses separated, maintainable files:


text
text
project-name/
├── index.html              ← Structure only. No inline styles. No inline scripts.
├── css/
│   ├── main.css            ← Reset, custom properties, shared components, cursor, grain
│   └── sections.css        ← Section-specific styles, each section clearly marked
├── js/
│   ├── app.js              ← Master init. Loads all modules. Registers GSAP plugins.
│   └── [one file per feature]
└── images/
    ├── hero/
    ├── editorial/
    ├── runway/
    ├── campaign/
    └── archive/


FILE RESPONSIBILITIES

index.html
Semantic HTML only
Links to css/main.css and css/sections.css
Links to CDN libraries (GSAP, Lenis, Google Fonts)
Links to js/app.js at end of body
Zero<style> tags
Zero<script> tags (except CDN <script src>)

css/main.css
CSS reset
Custom properties (:root)
Typography base
Cursor styles
Grain overlay
Header / Menu overlay
Footer
Mobile global overrides
Shared animation keyframes

css/sections.css
Each section clearly marked with a comment block:
css
css
/* =============================================
   SCENE 01 — THE LIGHT CRACK
   ============================================= */
Section-specific layout, spacing, and responsive rules
Ordered by page flow (top to bottom)

js/app.js
DOMContentLoaded wrapper
GSAP registerPlugin(ScrollTrigger)
Lenis init (with mobile check)
Calls each module in order:
js
js
initCursor();
initLoader();
initHero();
initScroll();
No animation logic lives here. It only calls.

js/[module].js
One function per file
Each file is self-contained
No module depends on another module
Shared state (Lenis instance, GSAP) passed via app.js or accessed via window
Naming: cursor.js, loader.js, hero.js, scroll.js, editorial.js, filmstrip.js, archive.js, atmosphere.js, marquee.js


JAVASCRIPT MODULE PATTERN

Each module file follows this structure:


js
js
function init[FeatureName]() {
  // All feature logic here
  // Uses GSAP, ScrollTrigger, Lenis from global scope (CDN loaded)
}

// Export for app.js to call
// If using app.js as the orchestrator:
// Just define the function globally, app.js calls it

If a project grows complex enough to need state sharing between modules, use a simple namespace:


js
js
window.MAREN = window.MAREN || {};
window.MAREN.lenis = lenisInstance; // set in scroll.js

WHEN A SINGLE HTML FILE IS ALLOWED

Only for:


Situation	File
Style guide sandbox (vibe check)	Single HTML, under 80 lines
Rapid prototype (testing ONE interaction)	Single HTML, disposable
Client quick preview	Single HTML, to be replaced

Anything that ships to production uses the full structure. No exceptions.



WHY THIS MATTERS

Problem	Solution
Finding one CSS rule in 800 lines	Each concern in its own file
Disabling one feature without breaking others	Each feature in its own JS module
Swapping images without touching code	Images in named folders, paths in HTML only
Client can edit text safely	HTML has no styles or scripts to accidentally break
Debugging one section	Open sections.css, scroll to the section comment
Onboarding a new developer	File names tell them where everything is

III. PROJECT DNA

Emotion: Stillness. The peace of looking at nothing and seeing everything. Like sitting in a zen garden where the rocks are the conversation and the space between them is the meaning.


World: A zen temple at dawn. Ink wash painting. Paper screens filtering light. The sound of a single water drop in a stone basin. The space between breaths. Rooms with nothing in them that feel completely full.


Archetype: Quiet Luxury (extreme)


Audience Fantasy: The person who understands that what's missing is more important than what's present. A curator, an architect, a philosopher of taste. Someone who finds richness in reduction.


Transformation: Viewer → Contemplative observer. They arrive expecting a model portfolio. They leave having experienced a meditation on emptiness.


North Star Moment: The viewer scrolls through complete white space for what feels too long — just enough to wonder if something is wrong. Then a single image fades into existence so slowly it's almost imperceptible. It arrives like a thought.



IV. COLOR SYSTEM

css

  --ink: #1A1A1A;         /* deep charcoal — text */
  --sumi: #6B6B6B;        /* ink wash grey — secondary */

Palette Logic:

White/cream DOMINATES. The page is 90% negative space.
Charcoal ink used only for text. Never for decorative elements.
Sumi grey used for secondary text, labels, subtle lines.
NO accent color. No gold. No warmth. No coolness. Just absence.
The "color" of this site is the ABSENCE of color.
When an image appears, the monochrome photograph is the only source of visual weight.

Scale Rules:

Section labels: 0.55rem / 4px letter-spacing / all caps / DM Mono
Japanese labels: Noto Serif JP at 0.7rem, no letter-spacing

Typography Behavior:

Text appears with extreme patience — clip-path reveal over 1.2 seconds
Characters never stagger. The entire word/line appears as one unit. Staggering would be too dramatic for this world.
Text opacity never exceeds 0.75 — it always feels like it's fading slightly, like ink that hasn't fully dried.


VI. SITE ARCHITECTURE

7 scenes. Extreme whitespace between each. The page breathes.



SCENE 00 — LOADER (THE BRUSHSTROKE)

A white screen. Nothing happens for 1.5 seconds. Then: a single horizontal brushstroke draws itself from left to center. It's not a line — it's a brushstroke: slightly uneven, with varying opacity, like sumi ink on rice paper. It holds for 0.8 seconds, then fades. The site appears behind it as the white screen lifts.


Implementation:

SVG path with stroke-dasharray/dashoffset animation
SVG has stroke-linecap: round and slight opacity variation via gradient
No text. No numbers. No percentage. Just the stroke.


SCENE 01 — NAME (THE ARRIVAL)

Pure white space. Then, from the center of the viewport, her name fades in:


text
text
田中  雪

YUKI TANAKA

The Japanese characters appear first (Noto Serif JP, 200 weight, clamp(2.5rem, 6vw, 5rem)). Below: the romanized name in DM Mono, 0.6rem, 0.4em letter-spacing, opacity 0.4.


Both are centered in the viewport. They hold for 3 seconds. Then they fade to 15% opacity and remain as a ghost in the background as the scroll begins.


Why Japanese characters first: It establishes the world before the Western reading pattern kicks in. The viewer must pause, look, read differently. The experience starts with a micro-moment of unfamiliarity.



SCENE 02 — PROLOGUE (THE THOUGHT)

After scrolling past the name (which has faded to a ghost), the first image appears. But not immediately. There is white space — a lot of it — enough to make the viewer wonder if they've scrolled past everything.


Then, slowly, an image fades into existence. It takes 3 seconds to go from invisible to visible. It starts at opacity 0 and arrives at opacity 0.85 — never full opacity. It feels like a memory forming.


Below the image, centered, a single line in DM Mono:


text
text
東京 — パリ — ニューヨーク

(Tokyo — Paris — New York, in Japanese)



SCENE 03 — THE GALLERY (ONE AT A TIME)

This is the core of the site and where it diverges from every other portfolio.


Rule: Only ONE image is ever visible at a time.


The gallery is a sequence of full-viewport panels. Each panel contains:

One image (centered, max-width 70vw, max-height 75vh)
A label below (DM Mono, 0.55rem, opacity 0.3): 001 — COMME DES GARÇONS FW24
Nothing else

Between each panel: at least 40vh of pure white space. The viewer must scroll through emptiness to reach the next image. This is intentional. The whitespace is not wasted space — it is the space between breaths in a meditation.


Scrolling behavior: Lenis at lerp 0.05. This is extremely slow. Every scroll increment feels deliberate. The viewer cannot rush through this site. It enforces contemplation.


Image count: 10 editorial images + 4 campaign images + 3 runway groups = 17 total panels.


Image animation: Each image enters via a 3-second fade from opacity 0 → 0.85. No clip-path. No scale. No parallax. Just a fade. The simplest possible arrival.

VII. ANIMATION SYSTEM

Element	Animation	Duration	Easing
Text reveals	clip-path inset(0 0 0 0) from inset(0 0 100% 0)	1.2s	cubic-bezier(0.22, 1, 0.36, 1)
Image arrival	opacity 0 → 0.85	3s	power1.out
Archive background	opacity 0 → 0.15	1.2s	power2.inOut
Name ghost	opacity 1 → 0.15	2s	power1.out
Brushstroke loader	stroke-dashoffset 0 → full	1.5s	power2.inOut
Scroll	Lenis lerp 0.05	continuous	—

No stagger animations. Words and lines appear as units.
No scale animations. Images don't zoom.
No parallax. Nothing moves at different speeds.
No rotation. Nothing tilts.
The only motion is opacity. Everything fades. That's it.



VIII. SIGNATURE INTERACTION — INK DISSOLUTION

Location: Scene 03 (The Gallery) — each image after it has been visible for 4 seconds.


Behavior:

1.Image fades in (3 seconds, opacity 0 → 0.85)
2.Image holds at 0.85 opacity for the duration of viewport visibility
3.As the image scrolls OUT of the viewport (bottom edge leaving), instead of simply scrolling away, the image applies:
filter: blur(0px) → blur(8px) over 1.5 seconds
Simultaneously: opacity: 0.85 → 0.15
Simultaneously: a CSS mask gradient appears, making the edges dissolve inward
4.The effect: the image dissolves like ink dispersing in water. It doesn't leave — it fades into the white page.

Implementation:

GSAP ScrollTrigger with start: "top top" and end: "bottom top" on each image container
scrub: 1 for smooth scroll-linked animation
CSS filter blur + opacity + mask-image animated via GSAP

Emotional Effect: Images don't disappear. They dissolve. They become part of the white space. Like memories fading. Like ink in water.
